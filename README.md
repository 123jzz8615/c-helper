# 竞途 AI（c-helper）

竞途 AI 是一个面向编程入门与算法竞赛学习者的个性化学习助手。它把学习目标、每周可用时间、基础诊断、课程学习、洛谷练习、错题复盘和学习报告串成一条完整路径，帮助学生回答“今天学什么、为什么学、做错后复习什么”。

当前仓库提供一个可直接运行的学生端技术 MVP。推荐逻辑是可解释的确定性规则，目前没有调用任何大模型 API。

## 当前实现概览

| 能力 | 当前状态 |
| --- | --- |
| 账号系统 | 注册、登录、退出、8 小时 Cookie 会话 |
| 初始诊断 | 根据回答动态追问，建立目标、时间、基础与薄弱项画像 |
| 每日计划 | 结合目标、截止日期、掌握度、错题、先修关系和本周剩余时间生成 |
| 课程体系 | 初始化后 40 个已发布知识点：基础篇 18 个、进阶篇 22 个 |
| 代码语言 | C、C++、Python；每个知识点各 1 个版本，共 120 个版本 |
| 课程学习 | 课前检测、知识概览、分层提示、代码骨架、参考答案、易错点 |
| 洛谷练习 | 基础/巩固/挑战分层，保存题目元数据和用户自报进度 |
| 错题闭环 | 记录错因、生成二次练习、安排复习、支持标记已解决 |
| 学习报告 | 练习数、正确率、开放错题、薄弱知识点、高频错因、下一步建议 |
| 数据库 | 本地 SQLite；部署时可切换 PostgreSQL/Neon |
| 部署 | 本地 Python HTTP 服务；支持 Vercel Python Serverless + 静态前端 |

## 主要功能

### 1. 账号与学习画像

- 用户名支持 3～20 位中文、字母、数字或下划线，密码长度为 8～72 位。
- 新用户登录后进入动态诊断，问题覆盖学习目标、每周时间、语言基础、算法经验、常见卡点和内容平台偏好。
- 诊断不是固定问卷：未选择“循环”或“数组”基础时会追加相应探测题；自报学过二分时会追加二分理解题。
- 诊断结果会写入目标画像和知识点掌握度，直接影响后续推荐。
- 用户可以在首页继续调整目标赛事、目标日期、每周学习时间、首选语言和当前水平。

当前支持的学习目标：

- 蓝桥杯
- CSP-J/S
- 洛谷入门
- 学校考试
- 系统自学算法

当前支持的每周时间档位为 3、5、8、12 小时，首选语言为 C、C++ 或 Python。

### 2. 可解释的每日学习计划

首页会按照 Asia/Shanghai 日期计算当天计划。推荐器综合以下信息：

```text
推荐分数 =
    目标匹配度 × 35%
  + 掌握缺口   × 25%
  + 错题需求   × 20%
  + 截止日期压力 × 10%
  + 学习准备度 × 10%
```

计划同时具备这些行为：

- 根据每周预算、本周已记录用时和本周剩余天数计算今日可用分钟数；
- 每天最多安排 4 个知识点；首个任务可以使用当天剩余的短时间，后续任务只在至少还剩 15 分钟时才部分安排；
- 开放错题会被优先加入候选，即使对应课程已经标记完成也不会自动消失；
- 必需先修知识点掌握度不足时，暂缓推荐进阶节点并明确展示阻塞原因；
- 输出推荐理由、推荐类型、预计/分配用时、计划完成度与备考节奏状态；
- 推荐算法版本当前为 `goal-plan-v1`。

注意：数据库已经定义每日计划快照表和持久化函数，但当前首页主流程是实时计算并返回计划，尚未自动保存每日快照。

### 3. 知识体系与课程目录

初始化数据库后会生成 40 个已发布知识点，并按“基础篇/进阶篇”和“入门/算法/数据结构/数学”组织。前端支持按阶段与分类筛选。

基础篇共 18 节：

- 入门：顺序结构、分支结构、循环结构、数组、字符串、函数与结构体；
- 算法：模拟与高精度、排序、暴力枚举、递推与递归、贪心、二分查找与二分答案、搜索；
- 数据结构：线性表、二叉树、集合、图的基本应用；
- 数学：基础数学问题。

进阶篇共 22 节：

- 算法：前缀和/差分/离散化、常见优化、分治与倍增、字符串、进阶搜索；
- 数据结构与图论：二叉堆与树状数组、基础/进阶线段树、树、最短路、最小生成树、连通性；
- 动态规划：引入、线性状态、区间与环形、树与图、状态压缩、设计与优化；
- 数学：进阶数论、组合数学与计数、概率与统计、基础线性代数。

系统还会初始化 47 条先修关系，并在启动时校验先修图无环。

### 4. 结构化课程学习

每个知识点包含一条完整学习路径：

1. 课前热身：结合上一节或本节起点进行自评，结果会调整掌握度与练习难度；
2. 知识点速览：学习目标、核心概念、知识关联、典型场景、常用模板、练习路径及复杂度；
3. 独立思考：通过反思问题先形成自己的解法；
4. 问题与解题思路：例题、自我练习和分步解法；
5. 分层提示：基础提示、逻辑提示、带 `TODO` 的代码骨架、完整参考代码；
6. 易错点与状态：查看常见错误，并标记“学习中”“已完成”或“复习”；
7. 练习记录：关联洛谷题目，记录结果、用时、提示次数、错因和备注。

课程支持实时切换 C、C++、Python，并可下载对应的 `.c`、`.cpp`、`.py` 代码骨架。系统只展示和下载代码，不会在服务器上编译或执行用户代码。

### 5. 洛谷题目与外部资源

- 每个知识点初始化至少 3 条洛谷题目目录元数据，按基础、巩固、挑战分层；
- 课前反馈和掌握度会决定本次显示的题目难度组合；
- 点击题目会打开洛谷公开页面，并记录“已打开”；提交练习后记录“用户自报完成”或“需要复习”；
- 系统不登录洛谷账号、不获取真实评测记录，也不保存完整题面、样例、题解或评测数据；
- `app/luogu_recommendations.json` 为部分入门知识点提供精细配置，其余节点会使用分类兜底题目，因此“每节至少 3 题”不等于所有映射都已完成独立教研审核。

课程页还会根据画像生成 Bilibili、抖音、洛谷、博客/题解和全网搜索入口。搜索功能只生成公开搜索词和链接，不自动抓取或判断搜索结果质量。登录用户可以登记已确认的公开资源链接；系统仅保存标题、URL、作者、标签和少量摘要等元数据。

### 6. 练习、掌握度与错题复习

一次练习可以记录：

- 结果：做对、部分正确、做错；
- 用时与使用提示次数；
- 关联的洛谷题号；
- 错因与个人备注。

部分正确或做错时必须选择错因，可选项包括读题错误、建模错误、算法错误、复杂度错误、实现错误、调试困难和其他。提交后系统会：

- 根据结果、用时和提示次数重新计算掌握度；
- 更新课程状态和技能画像；
- 创建开放错题，并默认安排次日复习；
- 按错因返回一条针对性的二次练习；
- 将关联洛谷题目标记为需要复习；
- 在开放错题解决前持续提高该知识点的推荐优先级。

错题本会展示错因、复习日期和二次练习，支持回到原知识点或将错题标记为已解决。

### 7. 学习报告

报告页按当前账号的练习数据汇总：

- 练习总数与做对数量；
- 正确率；
- 待复习错题数；
- 当前掌握度最低的知识点；
- 最常见的 3 类错因；
- 基于正确率和开放错题生成的下一步建议。

## 技术架构

```text
浏览器（原生 HTML / CSS / JavaScript）
              │ JSON API + Cookie
              ▼
app/server.py（Python 标准库 HTTP 服务与业务接口）
        │                    │
        │                    ├─ app/recommendation.py（每日计划）
        │                    └─ app/learning_rules.py（画像、分类与规则）
        ▼
app/db.py（建表、迁移、种子与校验）
        │
        ├─ SQLite：data/jingtu_ai.db（本地默认）
        └─ PostgreSQL / Neon（设置 DATABASE_URL 后启用）
```

项目没有 Node.js 构建步骤，也没有前端框架。后端主要使用 Python 标准库；`psycopg` 仅在使用 PostgreSQL 时需要。

### 数据初始化

服务启动时会自动执行幂等初始化：

- 创建或迁移账号、画像、课程、掌握度、练习、错题、推荐、洛谷和外部资源相关表；
- SQLite 启用外键、WAL 和 3 秒 busy timeout；
- PostgreSQL 使用事务级 advisory lock，避免多个 Serverless 实例同时初始化；
- 根据 schema/curriculum 版本标记走快速检查或执行修复；
- 写入课程、代码版本、课前检测、目标权重、先修关系和洛谷元数据；
- 校验分类、内容完整性、技能映射和先修图。

初始化后的种子数据契约如下：

| 数据 | 数量 |
| --- | ---: |
| 已发布知识点 | 40 |
| 基础篇 / 进阶篇 | 18 / 22 |
| C/C++/Python 代码版本 | 120 |
| 课前检测 | 40 |
| 先修关系 | 47 |
| 目标—知识点权重 | 200（5 个目标 × 40 个知识点） |
| 洛谷唯一题目元数据 | 27 |
| 知识点—洛谷题目关联 | 120 |
